The file consists of Aedt files of Ansys Electronics Student desktop.

Each file consists of a different Microstrip patch antenna designed at 5GHz that operates at different frequency bands.

E-slotted_HPA consists of stages Hexagonal patch antenna (HPA) ---> HPA with Semi-circular slots ---> HPA with E shaped Slot ---> HPA with slots and DGS.

LB_slotted_MM_DGS_MSPA consists of stages Rectangular patch antenna (RPA) ---> RPA with Lightning bolt shaped slot (RPAL) ---> RPAL with Metamaterial (RPAM) ---> RPAM with slots, metamaterial and DGS (RPAMD).

Pinwheel_slotted_MSPA consists of stages Rectangular patch antenna (RPA) ---> RPA with 1 to 4 Semi-circular slots ---> RPA with Pinwheel shaped Slot ---> HPA with slots and different shapes of DGS.
